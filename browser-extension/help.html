先保存网页。需要整理、检索和知识花园时，再连接同一个资料库。

第一次保存

  1. 打开要收藏的网页，点击浏览器工具栏的 Kumo。
  2. 点击“选择文件夹并保存”，选一个用于存放资料的文件夹；无需选择软件安装目录。
  3. 以后会记住这个文件夹。正文、来源和主要图片默认保存；完整视频与截图可在“保存设置”中按需开启。

无法授权文件夹时，在“保存位置”选“浏览器下载目录”。下载结果保存在 Kumo-Inbox 子目录，浏览器可能另行询问下载许可。

快捷剪藏与原文链接

Windows 默认 Ctrl+Q 一键剪藏当前网页。打开“保存设置 → 快捷剪藏 → 修改快捷键”，可在浏览器扩展设置中更改；已安装版本可能沿用旧键位，请以面板显示为准。macOS、Linux 默认 Alt+Shift+S。首次选文件夹或授权媒体需手动确认。

小红书会区分作品编号和带访问参数的完整链接。Kumo 用编号去重，打开原文时保留访问参数；重复保存也会保留已有的完整链接。原文仍可能因删除、权限变化或参数过期而不可用，本地正文和图片可继续阅读。

让 AI 使用收藏

桌面本地 Work / Codex 安装 Kumo AI 插件后，连接你刚才选择的资料文件夹。先说“检查 Kumo 连接”，再试“找一篇适合当前任务的收藏”或“整理新收藏，保留我的分类”。读取到的内容会进入当前 AI 对话。

浏览器扩展本身不编译知识。仅选择文件夹，也不等于已连接 ChatGPT。ChatGPT 网页或云端连接需要另行配置，当前安装包不自动公开本地资料。

我的收藏与知识花园

插件中的收藏列表、标签管理和花园需要 Kumo 本地助手连接同一资料库。未连接时，保存在文件夹里的内容仍在，可用文件管理器打开；连接失败不会清空收藏。

启用方式：安装发布包附带的“本地助手”（需要 Node.js 22 或更新版本），连接同一个资料文件夹，再在“保存位置”中选择“连接的本地资料库”。初次安装步骤见助手包内的说明。

检查本地连接

手动安装测试包

解压发布 ZIP。在 Edge 或 Chrome 的扩展管理中开启开发人员模式，选择“加载解压缩的扩展”，再选择直接含有 manifest.json 的文件夹。将 Kumo 固定到工具栏。更新文件后点一次“重新加载”。正式市场安装将省去这些步骤。

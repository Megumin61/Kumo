# Kumo 浏览器扩展 0.18.15

把用户主动选择的网页、来源、图片和笔记保存到本地目录。当前界面以简体中文为主，支持 Chromium / Microsoft Edge。

## 本地安装

1. 在 Edge 扩展页打开开发人员模式。
2. 选择“加载解压缩的扩展”，选择本目录（含 manifest.json）。
3. 首次打开选择收藏位置，索引准备后直接进入收藏页。之后日常浏览不用重新连接或选择目录。保存设置仍支持浏览器下载目录。

Windows 默认 Ctrl+Q 快速剪藏；实际键位可在“保存设置 → 快捷剪藏 → 修改快捷键”中查看与调整。首次保存需授权资料目录。

收藏列表保持单张封面；进入帖子详情后，多图按侧边栏宽度自适应为 1～4 列，保留图片原比例。最近新建或选择的标签优先显示，其余按收藏量排序；快捷收藏沿用上次选择，未选择时进入“未分类”。单条收藏使用简洁提示，多条同时保存时仅轻量补充剩余数量，最多同时处理 3 条，超出的自动排队。任务保留触发时的帖子快照；重复触发同一条进行中的任务不会重复启动。

在“保存设置 → 开发者模式”中开启“本页入口”，当前网页右下角会出现临时的“Kumo · 嚼一嚼”按钮。直接点击即可使用现有快捷收藏流程，并显示结果；点击 × 关闭，刷新页面后自动消失。它不会全站常驻，不需要连接额外脚本。

收藏列表与知识花园直接读取浏览器授权的资料库和本机索引，无需本地助手。AI 检索与编译是可选的单独插件能力。浏览器扩展不扫描 AI 软件安装目录，也不自带云端 AI 编译服务。

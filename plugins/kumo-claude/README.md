# Kumo · Claude 插件（纯 Skill 版 0.16.0）

Kumo 帮你把收藏变成 AI 能用上的参考。这个版本只有 Skill，没有后台服务，不需要安装 Node.js，也不用运行任何命令。Claude 直接读写浏览器扩展保存到的资料库文件夹。

## 安装

在 Claude 桌面端打开 `kumo.plugin`，点安装。它会替换旧版。

## 连接资料库

不用手动配置。Claude 会按顺序找：`~/.kumo/config.json` → 浏览器扩展写的 `~/.kumo/bridge-config.json` → 项目里的 `KUMO.md`，都没有才问你一次。云端会话里如果文件夹还没连上，会弹一次授权，你点同意即可。

## 技能

| 技能 | 怎么说 | 作用 |
|---|---|---|
| setup | 检查 Kumo 连接 | 确认资料库位置、数量和读写权限 |
| find | 在收藏里找…的参考 | 检索并读原文，说明哪里能用上（只读） |
| organize | 整理新收藏 | 分类、编译领域知识、更新关联；先给预览，再保存 |
| note | 记下来 / 存成笔记 | 把这次实践、实验或讨论存成笔记，逐个元素关联到用过的帖子 |
| kumo-library | 日常任务中自动判断 | 设计、研究类任务中按需参考你的收藏 |

## 笔记：嚼过的知识（0.16 新增）

收藏卡片记录「帖子说了什么」，笔记记录「我们拿它做了什么、量到了什么、想到了什么」。笔记不是单独的模块，而是第二种来源：

- 存在资料库的 `notes/` 文件夹，格式和收藏一样（`source.md` + `metadata.json`，代码和截图放 `assets/`）。
- 整理时和收藏一起编译：笔记有自己的卡片，用 `practices` / `discusses` 关联到用过的帖子，并写清用了帖子的哪个元素。
- 每个主题多出「可复用元素」和「实践记录」两栏，结论标明来源性质：实测 → 你的原话 → AI 推导 → 作者说法。
- 检索时先看主题里的元素和实践，再看笔记，最后回到原帖；没实践过的相关帖子也会一并列出。

规则见 `skills/kumo-library/references/notes.md`。

## 编译结果放在哪里

总结和编译方法与 Codex 插件 0.14.3 完全一致（编译协议、摘要写法、媒体处理、参考落地四份规则原样保留）。区别只在写入位置：

- `wiki/claude/`：Claude 编译的来源卡、领域方法和索引，Claude 下次检索会直接读。
- `tasks/`：同一批结果的编译提案。之后用 Codex 插件或 Kumo 命令行编译时，可以把它正式发布进 `wiki/kumo/state.json`。

`wiki/kumo/state.json` 和 `wiki/readable/` 归 Kumo 官方编译器管，这个插件不碰。原帖、媒体、你的笔记和人工标签也不会被修改或删除。

## 限制

- 视频只有在能运行 `ffmpeg` 的环境里才会抽帧查看，否则会标注「视频未看」。
- 没有向量检索，靠关键词和已编译的领域页定位；找不到时会直接说。
- 音频转写默认关闭，需要你授权才会把音频发给外部服务。

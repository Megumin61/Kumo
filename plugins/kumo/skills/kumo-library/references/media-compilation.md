# 媒体阅读与分层编译

用户授权编译后，先调用 `prepare_media`，需要读图中文字时加 `ocr:true`。默认完全本地：顺序整理全部已保存图片，长图分段，视频按时间与场景变化抽帧。`transcribe:true` 会把音频发送到已配置的转写服务，只有获得相应传输授权并具备有效凭据后才启用。失败状态必须保留，不能以空文字稿代替成功。

读取 `read_source(view:'prepared')`；必要时翻页。用 `read_image(name:'prepared/sheet-001.jpg')` 顺序阅读全部图片页，再读需要精看文字的 `prepared/preview-0001.jpg`。页内编号与 manifest 记录原资源、长图分段和视频秒数。拼图不能替代小字核验。视频抽帧仅提供视觉概览；转写只覆盖声音，均不代表完整观看或效果验证。

编译卡保存 `mediaFingerprint`。引用准备后的图片时，resource 使用 `prepared/preview-XXXX.jpg`，在 `inspectedImages` 记录实际阅读的预览；读过拼图时，只记录该页真正可辨认的图片。OCR 证据使用 `view:'ocr'`，定位到对应预览并摘录 normalizedText 或 text 中的原文；只读 OCR 不得声称看过图片。文字稿证据使用 `view:'transcript'`，摘录必须与成功文字稿一致。媒体缺失、无音轨、转写失败分别记录在 limitations。所有预处理产物在 derived/media 中，原文、媒体、笔记与人工标签不修改。

先判断材料实际重心，再选择总结重点：设计参考保留对象和视觉特点；教程保留目标、过程和前提；资源清单保留范围、差别与入口；观点保留判断、理由和分歧；个人笔记保留用户原意与未决问题，不视为永久偏好。

每篇帖子先一句话独立讲清是什么、讲什么，再用短段落展开关键内容。产品介绍不强制写步骤，观点不强制提炼方法。关键词2–5个，使用普通具体词。作者陈述、图片观察、评论和用户笔记分清来源；不把标题效果承诺当成验证事实。

主题归纳一个具体方面的知识、不同材料的贡献与差异。领域概括知识覆盖和可支持的任务；少量帖子不等于实际能力已提升。保留每层的来源入口。更新全部受影响节点与双端有据关系；相似词不是建立关系的充分理由。新增材料要复用合适节点，避免一篇一主题。

领域只归纳属于本领域及其子领域的主题，不因某篇帖子同时属于两个领域，就把它在另一领域的所有主题与认识也带进来。跨领域的启发用有依据的关系单独表达。领域优先保留三条能代表其覆盖范围的认识，不按主题排列顺序截取，避免漏掉重要分支。核验归纳质量时，同时检查摘要、主题归属、来源对应和待补内容，不能只统计编译数量。

检索时既可领域→主题→帖子逐步读取，也可直接找帖子。摘要提供定位，原件提供核验。媒体版本过期后，依赖它的卡和上层方法不能继续当作新鲜知识。

# Kumo · ChatGPT Work / Codex 本地插件

插件包版本 **0.13.4**，MCP 核心沿用已验证的 **0.13.3**。用于检索和整理浏览器剪藏；它是需要本地执行的插件，不是把电脑资料公开到云端的服务。

## 安装与连接

- 运行环境：Node.js 22 或更新版本。运行包已内置 JavaScript 依赖，无需 npm 安装。
- 在支持本地 marketplace 的桌面宿主中添加本仓库，选择 Kumo。市场索引为仓库根目录的 .agents/plugins/marketplace.json。宿主是否显示该入口取决于客户端能力。
- 如宿主支持导入便携插件 ZIP，可使用 本仓库 GitHub Releases 中的独立插件包；仅解压 ZIP 不代表宿主已安装。
- 安装后说“检查 Kumo 连接”，再明确指定并授权浏览器保存的资料文件夹。按 [安装说明](INSTALL.md) 配置。默认只读；需要整理时再开启派生写入权限。

## 使用例子

1. “找出我收藏中有关信息层级的三篇材料，读取原文并说明适用场景。”
2. “整理新收藏，保留我已有的标签，编译领域和主题知识，更新有证据的联系。”
3. “参考我保存的 GitHub 仓库说明，判断哪个适合当前任务。没有原文就说明缺口。”

检索不会自动写回；整理先预览再发布。收藏不会自动训练模型，当前模型实际读取的内容会进入它的上下文。无用户任务时不主动发通知，也不能保证每个相关问题都触发检索。

## 目录

- plugin.json / mcp.json：便携插件清单与本地 MCP 启动配置。
- skills/：设置与证据整理说明。
- mcp/：包含 JavaScript 依赖的运行文件，以及可选媒体处理脚本。
- src/mcp/：可维护的源代码、依赖锁和自动测试；此处没有 node_modules 或个人资料。开发验证可进入该目录执行 npm ci、npm test。
- assets/：用户选定的两套品牌图片。

## 公开目录状态

GitHub 分发和 OpenAI 插件目录上架是两件事。本地 MCP 的公开提交需要 OpenAI 批准并将提交组织加入白名单，且需发布者身份验证、适用的政策页面和审核材料。这个包保留完整本地能力；未通过移除 MCP 冒充完整的云端检索插件。参见 [官方本地插件要求](https://developers.openai.com/plugins/deploy/desktop-only)。

依赖许可见 THIRD_PARTY_NOTICES.txt。没有附带用户资料库、连接配置、账号凭证、真实收藏或聊天记录。

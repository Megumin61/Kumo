# Kumo AI 插件 · 本地版 0.13.3

这是桌面本地 Work / Codex 的插件包。ChatGPT 网页或云端需单独接入，并不随浏览器扩展自动启用。

## 开始使用

1. 先在浏览器扩展中保存一条网页，选一个资料文件夹；无需选择软件安装目录。
2. 在支持本地插件的宿主安装 Kumo。运行环境需要 Node.js 22 或更新版本；发布包已包含 JavaScript 依赖，无需另装 npm 依赖。
3. 在新对话说“检查 Kumo 连接”。未配置时会给出下一步，连接成功后再核对资料数量。
4. 告诉 AI 浏览器选用的资料文件夹，并明确授权连接它。插件中的 configure-library 工具脚本会验证目录；默认只读，支持整理需明确开启。已有配置不覆盖。
5. 重启连接或新开对话，试“找一篇适合当前任务的收藏”。需要写入知识时再说“整理新收藏，保留我的分类”。

本地连接配置保存在用户的 .kumo/config.json；环境变量 KUMO_MCP_CONFIG / KUMO_LIBRARY_ROOT 仍可指定配置，历史包内 local-config.json 保持兼容。连接配置和个人资料不能打进发布包。

## 能力说明

- 浏览器负责保存；宿主 AI 负责检索和编译。不是后台自动训练模型。
- 本地资料被实际读取时，相关内容进入当前模型上下文，不等于离线推理。
- 图片可以实际读取；抽帧/图像预处理需要 Python + Pillow，视频抽帧另需 FFmpeg。缺少时应说明证据缺口，基础文字检索不受影响。
- 在线转写默认关闭，需要授权向所用服务发送音频并提供有效凭证。
- 收藏列表和知识花园还需要 Kumo 本地助手连接同一资料库。
- 没有用户消息时不会自己发通知；任务中的隐式召回由宿主判断，不能保证每次触发。

## 不需要做的事情

不需要扫描软件安装位置、不需要公开本地目录、不需要关闭安全保护。配置失败不代表收藏为空。网页端若未连接，请勿把本地回环地址当成云端服务地址。

# OpenAI 公开目录准备状态

当前分发方式：GitHub / 本地桌面插件。**尚未上架 OpenAI 插件目录。**

这个插件通过本地 stdio MCP 读取用户授权的资料目录。根据 OpenAI 的 desktop-only 提交要求，需要提交组织获得本地 MCP 白名单和发布者身份验证。不能把回环地址当成云端 MCP，也不能删除检索服务后把不完整的包当成原产品发布。

已准备：

- 便携插件清单、完整本地运行包与两套产品图标。
- 设置 / 检索 / 授权整理技能，默认只读，不附带资料库或机器配置。
- 三条实际能力示例、源代码与可在隔离目录执行的自动测试。
- 公开源代码目录和 GitHub 分发入口。

公开提交还需确认或补齐：

- OpenAI 提交组织、本地 MCP 白名单和验证后的发布身份。
- 专门覆盖 AI 插件的数据处理政策与使用条款。浏览器扩展的政策不能直接冒用。
- 支持国家及实际支付安排，由发布者选择后写入元数据。
- 主机中对当前版本的新装测试、五个正向 / 三个反向审核案例及真实演示录屏（若目标提交流程要求）。自动测试结果不能冒充宿主验收或录屏。
- 门户要求的扫描和发布者法律声明。

官方依据：

- https://developers.openai.com/plugins/deploy/desktop-only
- https://developers.openai.com/plugins/deploy/submission

所有缺失字段保持缺失，不填写虚构网址、验证身份或演示录像。文件可用于本地分发；这不代表已经满足公开目录提交条件。

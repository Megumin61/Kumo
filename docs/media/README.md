## 素材与呈现方式

2026-10-25 制作。风格切换和交互使用当前产品的实际界面逐帧采样，不是生成式 UI。使用与静态截图相同的合成资料库；剪藏面板、列表和合集镜头来自用户为本次产品展示提供的截图。

演示压缩了操作和停留时间。字幕、编号、章节卡与片尾属于展示包装，不表示新增了产品功能。画面中的合成编译卡不代表一次真实 AI 编译验收。视频无配音、无背景音乐，不含发布者凭证或账号页面。

画风包括：纸光花园、套色花园、彩铅纸贴、秋日墨线手记、绿调蜡笔文具、奶油日常涂鸦、森林奶油印章、复古杂货墨线、户外图解手帐、露营漫画贴纸、彩铅奇想手记。

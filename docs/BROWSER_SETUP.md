# Kumo 浏览器扩展 0.19.2

视频默认离线保存；页面原字幕随内容保存，翻译和关键帧在 AI 整理时按需处理。能力边界与状态含义见 [视频保存说明](VIDEO_SAVING.md)。

## 安装与首次使用

1. 从 GitHub 下载浏览器扩展包并解压。在 Edge / Chrome 扩展管理页开启开发人员模式，选择“加载解压缩的扩展”，加载含 `manifest.json` 的文件夹。
2. 打开 Kumo，首次点击“开始使用”，选择实际保存收藏的文件夹。已有资料库直接选择原位置，不要在里面再建一个副本。
3. 首次索引准备完成后自动进入收藏页。此后直接打开收藏即可；无需本地 HTTP 助手，也不需要每次连接或重选目录。

浏览器提供长期访问选项时，选择“每次访问都允许”或“始终允许”，便于自动同步和继续保存。长期权限由浏览器和用户控制，插件不能强制开启。

## 日常使用

- 收藏页和知识地图默认直接展示内容，主界面没有连接、更换文件夹按钮。
- 更换位置、检查授权和手动同步在“设置 → 收藏位置与同步”中。
- 收藏列表与地图不再在每次打开时强制扫描全库。先读取绑定原目录的本机索引；超过 30 秒的旧索引在有权限时后台核验，有变化才更新界面。保存收藏或修改笔记/标签会立即使旧索引失效。
- 临时权限失效后，已建立索引的正文、笔记和已缓存小图仍可在本机查看。界面标明“本地索引”及更新时间。新文件变化、未缓存媒体和写入仍需在设置中恢复访问，不能把缓存当成刚同步的磁盘内容。
- 缩放只调整数字、标签等信息，不隐藏已经展开的地图节点。收藏聚落保留完整来源节点和同一领域内的图案混搭。

## 缓存与资料安全

索引保存在此浏览器扩展的 IndexedDB 内，包含已读取的正文、元数据、用户笔记和派生知识视图。小图按需缓存，最多保留 64 张，每张不超过 1 MiB；视频和大媒体不完整复制。图片靠近可视区域时才读取。

缓存通过目录句柄的 `isSameEntry` 校验绑定原资料库，换目录不会展示另一资料库的缓存。明确拒绝读取权限时不继续读取索引。缓存不会上传至远程服务，也不会改写原件。

浏览器清理或卸载扩展可能移除本机索引；原始文件仍留在选择的资料目录中，可在首次引导中重新建立索引。

## AI 可选安装

浏览收藏和地图不需要 Node.js 或独立本地助手。按任务检索和编译知识可另行使用兼容的 AI 插件，关联同一份资料库；参阅 [AI 插件安装说明](../plugins/kumo/INSTALL.md)。安装浏览器扩展不等于 AI 已自动获得本地文件权限。

## 更新旧版本

重新加载扩展并关闭旧收藏/地图页，再重新打开。首次更新需要建立一次索引；后续打开优先使用已有索引。商店版本与 GitHub 源码/分发包分开发布。

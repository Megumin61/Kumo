# 官网产品体验

官网的可交互花园直接使用 `browser-extension/garden` 中的产品代码，不再维护另一套简化 SVG 图。

## 复用范围

- `vector-garden.mjs`、布局、轮廓、藤蔓、节点、搜索、阅读、图鉴、外观、导航等 121 个 JS/CSS 文件保持逐字节一致。
- 真实节点图集、纸张和官方双款标识直接使用产品资源。
- `docs/product/source-manifest.json` 记录复用文件的 SHA-256。
- 修改产品代码后，运行 `node scripts/sync-site-demo.mjs` 同步官网副本；运行 `node scripts/check-site-demo.mjs` 检查一致性与示例数据。

## 仅用于官网的适配

- HTML 包装增加公开演示提示、资源策略和 `demo-host`，不改变产品组件。
- `garden-endpoints.mjs` 指向同目录的 `knowledge.json`，不连接本地助手。
- 57 篇虚构收藏、6 个领域、18 个主题，由 `docs/demo-content.json` 生成；3 篇保留待编译状态。没有复制个人资料。
- 阅读原件入口指向 `sample.html`，展示明确标注的示例正文。
- 官网通过校验来源的消息同步视图与画风。沉浸体验只改变外层容器。
- 使用产品自身的浏览器存储保存外观与练习笔记；此站点的记录与本地资料库互相独立。

## 本轮核验

浏览器检查：真实知识花园展开、收藏聚落、搜索到帖子详情、示例原件链接、11 套画风同步、产品内选择反向同步到官网、沉浸模式。响应式和资源检查随发布执行。
